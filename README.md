# 🧠 MentorBridge Backend

Welcome to the FastAPI backend for **MentorBridge**, a women-centric mentorship platform that uses AI to foster meaningful connections between mentors and mentees across career stages.

This repo powers features like role-based onboarding, AI-assisted matching, affirmations, and conversation coaching—all built with ❤️ and serverlessly deployed on AWS.

---

## 🌟 Features

- ✨ Gemini-powered affirmations, intro messages, and summaries
- 🔒 Auth0 authentication for mentors and mentees
- 🤝 Role-based matching and secure user profiles
- 🧠 AI support: conversation coaching, anonymous asks, and win celebrations
- ⚙️ Clean FastAPI architecture with modular Lambda deployments

---

## 🏗️ Tech Stack

- **FastAPI** for the API framework
- **AWS Lambda** (Serverless) for deployment
- **Auth0** for user authentication
- **Google Gemini API** for AI content
- **MongoDB Atlas** for user and session data
